Red del proceso

Reglas del blueprint federado

  1. 1Custodia distribuida Cada organización conserva sus repositorios y responsabilidades legales.
  2. 2Intercambio por finalidad Solo circula la evidencia requerida para un caso de uso y una decisión explícita.
  3. 3Mínimo necesario Las vistas por rol excluyen datos no pertinentes para la finalidad declarada.
  4. 4Responsabilidad visible Cada suministro, consulta y escalamiento tiene responsable y plazo.
  5. 5Trazabilidad auditable Toda consulta, decisión y cambio de estado deja registro verificable.
